## Improvements

- Test branch migration through the actual upstream Git Updater metadata and update hooks for pinned legacy and current versions.

## Bug Fixes

- Correct the branch migration hook to process resolved repository objects, preserving the stable release channel when newer Git Updater versions have cached main.
- Keep remote version checks and update generation on the same verified production branch, while preserving other repositories and selected test branches.

## Upgrade Notes

- This release includes the renewal and badge APIs from 2.3.0. Upgrades from 2.2.0 must follow the payer_name/bono_renewal client guidance in release-notes/2.3.0.md.
- If a cached Git Updater source download fails with Unsupported Media Type, refresh Git Updater data or upload the versioned release ZIP and replace the existing plugin. The updater correction takes effect once this version is installed.
