## New Features

- None.

## Improvements

- Production updates now track `stable`, which advances only after the published release ZIP, checksum, notes and tag commit are verified against the exact CI-tested artifact.
- Added safe recovery of already published matching releases, serialized publication, failure summaries and scheduled release health checks.
- Migrate Git Updater's cached `main` production selection to `stable`, preserving other test branches.

## Bug Fixes

- Removed the unsupported `Tested up to` PHP header that blocked 2.3.0 publication; retain WordPress compatibility metadata in `readme.txt` and reject the header in release guards.
- Prevent failed releases from advertising an unavailable version and causing repeated installation of an older ZIP.
- Corrected the documented installable folder to `bono-arm-api/`.

## Upgrade Notes

- This release includes the renewal and badge APIs prepared for 2.3.0, whose publication failed. When upgrading from 2.2.0, review `release-notes/2.3.0.md`: renewal requests use `payer_name` and payment extras use `bono_renewal`. Obtain fresh previews and reconcile interrupted operations before replacement.
- Renewal and badge mutations remain disabled by default. Validate the installed ARMember lifecycle in staging before enabling renewal mutations.
