## New Features

- Added authenticated v2 endpoints to list available badges, list a user’s stored badges, assign an existing badge, and remove a specific badge from a user.
- Added the disabled-by-default Badge endpoints setting and dedicated `bono_arm_api_manage_badges` capability, granted to administrators.

## Improvements

- Badge mutations are idempotent, preserve other badge assignments, and share member locks with other Bono member operations.
- Added badge API documentation, OpenAPI and Postman contracts, translations, and regression coverage.

## Bug Fixes

- None.

## Upgrade Notes

- Beta for staging validation against inspected ARMember Pro 8.1.1 badge support.
- Enable Badge endpoints in Settings → Bono API before use. PUT and DELETE need no request body.
- Removing a badge clears all its stored awards for the target user; automatic ARMember rules may award it again later.
- Includes the renewal fixes from beta.2. Nothing is deployed or published by building this package.
